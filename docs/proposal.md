# 自然物記録・共有Webアプリ 企画案

## 1. 概要

現実世界で発見した自然物を，位置情報・写真・発見日時などとともに地図上に記録し，蓄積・共有できるWebアプリケーションを構築する．

植物，石・鉱物，木の実・種子などを対象とし，自然物そのものだけでなく，「いつ，どこで，どのような自然物を発見したか」という情報を記録する．

## 2. 目的

- 自然物の発見場所や特徴を継続的に記録する．
- 地図上で過去の発見記録を振り返る．
- 自然物の発見情報を他のユーザーと共有する．
- 地域ごとの自然物の分布や発見傾向を把握できるようにする．

## 3. 対象とする自然物

初期バージョンでは以下の3カテゴリを対象とする．
ただし，後から追加できるようにする．

- 植物：花，草，樹木，苔，シダなど
- 石・鉱物：岩石，鉱物，鉱石，結晶など
- 木の実・種子：どんぐり，松ぼっくり，種子など

## 4. 主な機能

### 4.1 自然物の記録

発見した自然物を写真とともに登録する．

記録項目：
- 写真（複数枚対応）
- 名前
- カテゴリ
- 発見場所（GPS）
- 発見日時
- 説明
- タグ

名前が分からない自然物も不明として登録できるようにする．

### 4.2 地図表示

登録された自然物を現実世界の地図上に表示する．

- 発見場所にピンを配置
- ピンから自然物の詳細を閲覧
- カテゴリ,名前ごとの表示切り替え
- 地図上の表示範囲による絞り込み
- 現在地の表示

### 4.3 検索・閲覧

- 自然物の名前による検索
- カテゴリによる絞り込み
- タグによる検索
- 発見日時による絞り込み
- 地域による絞り込み

### 4.4 記録管理

- 自分の登録した自然物の一覧表示
- 登録内容の編集・削除
- 公開・非公開の切り替え
- カテゴリ別の登録件数表示

### 4.5 記録の共有

登録した自然物の記録を一般公開できる．

- 公開記録は誰でも閲覧可能
- 非公開記録は投稿者本人のみ閲覧可能
- 投稿・編集・削除は管理者本人のみ可能

## 5. 利用者・アクセス制御

本アプリは，記録を投稿する管理者と，記録を閲覧する一般ユーザーに分ける．

| 利用者 | 閲覧 | 投稿 | 編集・削除 |
|---|---|---|---|
| 一般ユーザー | 公開記録のみ | 不可 | 不可 |
| 管理者 | 全記録 | 可 | 可 |

投稿・編集・削除を行う管理画面にはCloudflare Accessによるアクセス制限を設ける．

一般ユーザー向けの閲覧画面には認証を要求しない．

## 6. 画面構成

1. 地図画面：自然物の発見場所を地図上に表示する．
2. 自然物詳細画面：写真，名前，カテゴリ，発見場所，説明などを表示する．
3. 登録画面：自然物の写真や情報を登録する．
4. 管理画面：自分の記録の一覧表示，編集，削除を行う．

## 7. 技術構成

| 分類 | 技術 |
|---|---|
| フロントエンド | React |
| 言語 | TypeScript |
| ルーティング | TanStack Router |
| データ取得 | TanStack Query |
| 地図 | MapLibre GL JS |
| 位置情報 | Geolocation API |
| バックエンド | Hono |
| データベース | Cloudflare D1 |
| 画像保存 | Cloudflare R2 |
| 認証・アクセス制御 | Cloudflare Access |
| ホスティング | Cloudflare Workers |

Cloudflareのサービスを中心に構成し，インフラ管理の簡素化を図る．

## 8. 初期開発範囲（MVP）

初期バージョンでは，以下の機能を優先して実装する．

- 自然物の写真登録
- カテゴリ設定
- GPSによる位置情報取得
- 発見日時の記録
- 地図上へのピン表示
- 自然物の詳細表示
- 記録の編集・削除
- 公開・非公開設定
- 一般ユーザーによる公開記録の閲覧
- Cloudflare Accessによる管理画面の保護
